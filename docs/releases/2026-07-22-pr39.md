## Verified release gates

PR #39 keeps the hydrated mobile menu while adding a localized, server-rendered
navigation fallback for browsers where JavaScript is disabled. The fallback is
outside the sticky header so it scrolls away and cannot permanently obscure
main content in a short viewport. Hydrated and fallback menus share one link
renderer, which keeps primary routes, Support, language switching, and
`aria-current` state aligned.

Current sections now have a persistent visual cue: the desktop navigation uses
the existing three-pixel underline, mobile and fallback navigation use a blue
start border plus pale background, Support uses a visible underline, and
forced-colors mode uses a `CanvasText` border. The Avenir-first typography
restored in PR #36 is unchanged.

checks, ESLint, TypeScript, 216 unit and contract tests, 15 release-smoke
helper tests, coverage thresholds, the high-severity dependency audit, the
private-runtime build and leak checks, and the 38-entry Next.js build. The
candidate and production browser jobs each completed 105 cases: 104 passed,
