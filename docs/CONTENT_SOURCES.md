# Public content source register

This register records the provenance and publication boundary for the public
HELP Math history, research, and collaborator content. It is a copy-review aid,
not a substitute for legal, rights, or partner approval.

Sources are treated in three different ways:

- **Stable external record:** an agency, ERIC, DOI, award-owner, or publisher
  page that readers can inspect. Link to it; do not mirror it without permission.
- **Owner archive:** retained historical evidence whose public republication,
  third-party content, and accessibility status still require review.
- **Legacy live locator:** a temporary `helpprogram.net` location used to find
  source material before cutover. It must not be the only long-term evidence for
  a public claim because the same URL will later redirect to `helpmath.ai`.

## Legacy source custody before cutover

For every historical page or file actually used in public copy, the source
owner should record the following outside the public web tree before changing
the old domain:

| Required field | Publication reason |
| --- | --- |
| Original URL and original filename | Maintains traceability after the URL begins redirecting. |
| Capture date and HTTP result | Distinguishes a verified capture from an untested recollection. |
| SHA-256 and byte size | Establishes which exact edition was reviewed without publishing it. |
| Document date, creator, and version where known | Prevents claims from drifting across historical editions. |
| Rights owner, republication decision, and third-party content review | Separates evidence custody from public-download permission. |
| Accessibility review status | Prevents a source PDF from being presented as publicly ready solely because it opens. |
| Stable external replacement, if one exists | Reduces dependence on the retired domain and favors inspectable primary records. |

`LEGACY_RESOURCE_MAP.md` records the corresponding legacy-to-canonical routes
and the current external-source preference. It does not grant publication
rights.

The finite capture inventory is machine-readable in
`data/legacy-source-registry.json`. The allowlisted crawler writes original
bytes only to the external archive root named by that registry; the repository
retains metadata-only crawl evidence under `docs/evidence/`. Validate locator
coverage and manifest consistency with:

```bash
node scripts/validate-legacy-source-custody.mjs
```

Passing metadata validation proves registry/crawl consistency, not remote
durability, rights clearance, accessibility conformance, or approval to
republish. See `LEGACY_SOURCE_CUSTODY.md` for the reproducible capture protocol,
current counts, and remaining owner decisions.

## Copy rules

- Keep “HELP Math 1.0” attached to historical findings.
- Describe HELP Math 2.0 as a planned next phase until a release is independently confirmed. Do not publish confidential module details without Boulder Learning’s written public-release approval.
- Describe WWC as a single-study evidence review, never as an award or blanket product rating.
- Preserve contradictory or null findings alongside positive findings.
- Label legacy program pages and program-authored PDFs as historical or
  self-reported; do not let a modern redirect become circular proof of a modern
  claim.
- Link to agency, bibliographic, award-owner, and publisher records instead of
  mirroring third-party files unless permission is documented.
- Re-review links and ensure the partnership remains current before each production publication.
